# 1000組のもとにした統計

シミュレーションの1000組（`app/src/sim/population.ts`。すべて作った家族で、実在の人物ではない。町だけは実在の市区町村）は、下の割合から作っています。数字の正本は `app/src/sim/stats.ts` で、この一覧はそこから書き出しています（`app/src/sim/population.test.ts` が食い違いを止めます）。

- **統計**: 公的な統計・一次の出典の数字そのまま
- **推計**: 出典の数字から計算した物（計算のしかたは「注」）
- **近似**: 手元に統計が無いので置いた物（理由は「注」）。都合のよい作り話で埋めないため、ここに全部書きます

1組は、全国の1年の出生の 1/1000（2025年 671,270人 ÷ 1000 ≒ 671家族）にあたります。報告の「全国に直すと年に約◯家族」は、1000組の中の数 × 671 です（双子の家族も1家族）。

## 早送りの検査での家族の動き（仮定）

統計ではなく、検査のための動きの仮定です。30家族の検査と同じ作りに合わせています。

- どの家族も今日（2026-11-03）から使い始める（使い始める前に期限が過ぎた事は済み扱い。アプリの「途中から使い始めた家族」と同じ）
- 母とパートナーは毎日、自分の画面の一番上を1つ済ませる。夜勤の父は3日おき、単身赴任の父は7日おきで、生まれてから10日は手を付けられない。同居の祖父母は2日おき
- ふだんの検査（`npm run sim`）は1週おき＋節目の日（届出・出産の前後・生後14日・1か月・3か月・1歳・2歳など）だけ画面を確かめ、間の日に家族が動いた分は、確かめる日の前にまとめて動かす（近似）。全部の日を通すのは `npm run sim:full`
