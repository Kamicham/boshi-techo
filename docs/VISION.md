# ビジョン

## 一行

1948年、日本は母子手帳を発明した。2026年、その次の形を作る。「読む手帳」から「一緒に動く手帳」へ。

## 第一原理

1. 出産は一生に1〜2回。練習ができず、上達する前に終わる。
2. 全体を持っている人がどこにもいない。役所は手続き、産院は体、会社は休業、親は手伝い。つなぐのは家族だけで、その家族が一番経験が無い。
3. 一番つらい時に、一番やる事が多い。産後の眠れない数週間に、出生届（14日以内）・保険・手当・保活が重なる。
4. 「分からなくて怖い」が、次の子をためらわせる。

→ 足りないのは情報ではなく、**全体を持って先回りして動いてくれる誰か**。お金のある家は人を雇って手に入れている。それを、すべての家族に。

## 理想の姿（妥協しない7つの性質）

1. **入力ゼロ** — 家族は話すだけ、撮るだけ。必要な事はその時に1つだけ聞く。
2. **1000日を生きる** — 子どもを考えた日から2歳まで。週数・月齢で自分から起き、どの町の制度もその都度取りに行く。
3. **答えずに、動く** — 下書き・期限・予約・持ち物・連絡文。家族がするのは最後の「OK」だけ。
4. **家族全体の参謀** — 母だけのアプリにしない。パートナーには今週の仕事、遠くの祖父母には彼らの言葉で。負担の偏りを数字で見せて組み替える。
5. **医療は壁でなく橋** — 体の判断はしない。気になる事を日付つきで記録し、健診の15分を最強にする質問リストを医師へ渡す。
6. **家族が育てる地図** — ある家族が確かめた答えが次の家族へ。全国の自治体の「窓口の知恵」を、使う家族が育てる。
7. **子どもへの贈り物** — 1000日の記録と話しかけた声が、最後に一冊になり、いつか子どもに手渡される。

## 1週間の方針

完成度より、アイデアと方向が完璧であること。7つすべてに「本物が少し動いている」骨格を通しで作り、動画では**作った家族**の1000日を3分で早送りして見せる。
